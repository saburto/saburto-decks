## An imported file

A deck can be written as several files. This slide lives in
`decks/reused/imported.mdx`, and `decks/example.mdx` pulls it in where a slide
would be, with <Mark type="highlight">`<Slides src="./reused/imported.mdx" />`</Mark>.

A file can hold several slides, and the deck counts them as its own: the counter,
the arrows and the contents move through them like any other slide.
